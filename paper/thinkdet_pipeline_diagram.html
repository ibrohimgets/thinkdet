ThinkDet Overview (GroundingDINO + InternVL3.5-1B + TMA)
Figure: ThinkDet pipeline overview. GroundingDINO provides the main open-vocabulary grounding path (text encoder, vision encoder, decoder, and detection heads). ThinkDet adds a frozen InternVL3.5-1B branch that extracts intermediate layer-9 hidden states, compresses them with a trainable Text Memory Augmenter (TMA; \(M=8\) summary tokens), and injects them into the GroundingDINO decoder text memory via gated residual fusion at selected layers (e.g., \(\{1,3,5\}\)). This targets semantically under-specified prompts (functional and ambiguity-heavy queries) while preserving baseline behavior through zero-initialized residual fusion and preservation regularization.
