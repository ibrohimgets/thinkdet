Figure: ThinkDet Architecture. The pipeline consists of two parallel streams. Top (Baseline): GroundingDINO processes images via Swin-T and text queries via BERT, feeding into a 6-layer detection decoder. Bottom (Trainable): To handle reasoning-heavy prompts, the same image and query are embedded into a frozen InternVL3.5-1B. Hidden states (Hvlm) from layer 9 are passed to the TMA Augmenter, which produces 8 summary tokens (scaled by tanh(α)). These are integrated seamlessly via Residual Fusion, dynamically adjusting the text memory inside detection decoding layers {1, 3, 5}. The gate α is initialized securely at 0, forcing baseline equivalence at initialization.
